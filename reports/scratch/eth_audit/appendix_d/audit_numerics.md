# Appendix D, tested by computation

Audit of Appendix D ("A sharper bound for exact counting") of *The Exponential Time Hypothesis is False* (OpenAI, 17 Oct 2026, rev. 25 Oct 2026), by implementing its concrete objects at small size and comparing numbers. Text line numbers refer to `paper_flow.txt`; the formula-dense displays were also read from the rendered PDF pages (58, 60, 62). All arithmetic is exact (Python integers, `Fraction`, residues mod `2^P`) unless a line says "real-valued bound". Scripts are under `numerics/`; everything ran under `nice -n 19` on one core, about 25 core-minutes in total.

## Verdict

Every exact identity in Appendix D that can be instantiated at small size held on every instance tested. The D.2 encoding of a k-CNF contracts over `Z/2^{n+1}` to the brute-force model count on 1,800 random formulas with `n ≤ 12` (0 mismatches). The D.3 / Lemma D.2 encoding — the lift `B_i`, its multilinearisation, the congruence (D.2), the degree bound `K`, the subset-sum inversion and the array-indexed wire network summed over all arrays — agrees with the brute-force zero count on 22 systems with `n ≤ 6`. Lemma D.5 holds exactly as stated (the (D.10) valuation identity on 30 parameter sets, the Hermite identity (D.9) and the mod-`2^p` recovery from lifted residues on 90 cases, with at least 57 bits of slack in its precision budget). One level of the D.4 recursion, built literally (Lemma D.3 packets, (D.7)–(D.8), the mode expansion (D.12), the children of D.4.6), satisfies the exact identity (D.16) on toy networks, with Lemma D.4's integrality and the mode-coefficient divisibility holding at every crossing pair. Lemma D.3's expectation bound holds exactly over all labellings of tiny networks, and the interpolation points of D.4.1 have unit pairwise differences and unit Vandermonde determinants. **No ERROR was found.** The most serious finding is about the constants the appendix fixes: with `ε = 1/131072` the recursion's first parameter `u_0 = ⌊ελ⌋` is zero for every `s < 2^{131071}`, so `h = ⌈3M/u⌉` is undefined and Lemma D.5 (which needs `u ≥ 1`) never applies and the "fixed finite range of smaller sizes handled by direct summation" is every input of fewer than `2^{131071}` wires; the inequalities (D.5) first hold at `λ ≥ 2^{85}`; and the appendix's own child-count estimate (D.15) exceeds `2^M` for the root call unless `u_0 > 1973` (`s ≥ 2^{2.6·10^8}`) and exceeds `2^n` for 3-CNF at density 4.26 unless `u_0 > 4·10^6` (`s ≥ 2^{5·10^{11}}`). The sharper bound of Theorem 1.1 is therefore an asymptotic statement with no computable crossover; nothing in it is wrong at any size we can test, and nothing in it has content at any size we can represent.

## Findings

**1. GAP — the fixed constants put every representable instance in the "direct summation" range, and the proved exponent is below `n` only for `log₂ s ≳ 10^{12}`.** Claim (lines 4683–4700, PDF p. 58): `ε = 1/(128·1024)`, `r = 64`, `H = ⌈s/⌊√λ⌋⌉`, `u_d = ⌊ελ/2^d⌋`, `a_d = 2Σ_{j≤d} u_j`, `L = 2^a`, `D_arr = r^{2a}`, "All estimates below hold for sufficiently large s ... A fixed finite range of smaller sizes is handled by direct summation"; (D.5) `λ^{4/5} ≤ u`; Lemma D.5 requires `1 ≤ u ≤ a`; (D.15) the number of exponent tuples is `exp(O(√(M p_t/D)))` with the displayed estimate `exp(θ p_t + (6M/D) Σ_j −ln(1−e^{−θj}))`, `θ = √(M/(D p_t))`. Computed (`parameters.py`, exact integers; the tuple-count lines are real-valued bounds and exact big-integer counts):
- `u_0 ≥ 1` needs `λ = ⌈log₂ s⌉ ≥ 2^{17}`, i.e. `s > 2^{131071}`. Below that `u_0 = 0`, `h = ⌈3M/u⌉` is undefined, `a = 0`, `L = 1`, `S = {−1, 0}`, and Lemma D.5's hypothesis `1 ≤ u` fails. `u ≥ λ^{4/5}` in (D.5) needs `λ ≥ ε^{−5} = 2^{85}`, i.e. `s > 2^{2^{85}−1}`. (D.6) at `λ = 2^{17}` needs only `s ≥ 2^{575}`; `D_arr ≤ s^{1/1000}` holds whenever `a ≤ 4ελ` (exponent ratio `48/131072 < 1/1000`); `6M/r = 3M/32 < M/8` and `d ≤ log₂λ/6 + O(1)` are consistent.
- At the root with the text's own `p_t = p + 8hD_t + 8M(a+1)`, `h = ⌈3M/u_0⌉`, `D = L = 2^{a_0}`, `N = 6M/D` modes per weight, the displayed estimate, minimised over `θ`, is `2π√(M p_t/D)/ln 2 → 44.41·M/√u_0` bits for large `M` (at the text's `θ` it is `(1+π²)/(2π) = 1.73` times larger: `85.9 M/√u_0`; both are `O(M/√u)`, so this is not an error). Table (bits per wire, `M = 10^6`, `p = M/45`): `λ = 2^{17}`: 49.7; `2^{18}`: 34.5; `2^{20}`: 15.7; `2^{24}`: 3.9; `2^{28}`: 0.98; `2^{32}`: 0.25; `2^{40}`: 0.026. Direct summation of the same call costs 1 bit per wire; the trivial `2^n` costs `1/45` bit per wire for 3-CNF at `m = 4.26n` (the D.2 network has `2(2km − 3n) = 45.1n = 8.6s` wires when every variable occurs ≥ 3 times). Hence the estimate is below `2^M` only for `u_0 > 1973` (`λ ≥ 2.6·10^8`, `s ≥ 2^{2.6·10^8}`) and below `2^n` only for `u_0 > 3.99·10^6` (`λ ≥ 5.2·10^{11}`).
- Exact counts (big integers) at `u_0 = 1, a_0 = 2`: `M = 4`: `2^{177.4}` tuples (estimate `2^{198.8}`, direct `2^4`); `M = 8`: `2^{359.0}` (`2^{397.4}`, `2^8`); `M = 16`: `2^{722.8}` (`2^{794.6}`, `2^{16}`). So (D.15) is tight to within 10 % in the exponent at the first parameters the recursion would use, and the root call then enumerates `2^{45M}` children where direct summation costs `2^M`. A rigorous lower bound (weight-1 modes only, `C(N+p_t−1, N)`) already gives 11.7 bits per wire at `λ = 2^{17}` and 4.0 at `2^{18}`.
- Summing the per-depth estimate with `M_d ≤ Cs·8^{−d}`, `u_d = ⌊ελ/2^d⌋`: total `≤ 44.41·1.2147·√131072·C·s/√λ = 19,530·C·s/√λ` bits, plus `H = s/√λ` for the leaf. With `C = 4k` (D.2 network) this is below `n` only for `λ > 1.5·10^{12}` (k = 3, m = 4.26n), `2.2·10^{11}` (k = 3, m = n), `9.8·10^{10}` (k = 2, m = n). These use only the explicit constants; the unquantified `O_C(1)` thresholds can only push the crossover up.
Severity: GAP. The theorem is asymptotic and these numbers do not contradict it; but the appendix fixes its constants explicitly, and with them Theorem 1.1's sharper bounds have no content at any `s` with fewer than `10^{11}` binary digits, and the manuscript states no crossover.

**2. AMBIGUITY (extraction, not the paper) — `D_arr = r2a` in `paper_flow.txt`/`paper_layout.txt` (line 4688) is `D_arr = r^{2a}` in the PDF (p. 58, eq. (D.4)).** With labels in `[r]^a` on each side there are `r^{2a}` ordered pair-label classes, and Lemma D.3's "`H_pad D_arr/L ≤ 3M/L` packets" and "a given symbol occurs in exactly `1/r` of all padded pair labels" balance only with `r^{2a}`; read as `r·2^a` the lemma would be false for `a ≥ 2`. Likewise `H = ⌈s/⌊√λ⌋⌉` and `u_d = ⌊ελ/2^d⌋` lose their brackets in the extraction. The reading agents should use the PDF for (D.4). (Checked exactly: Lemma D.3's `E Σ_γ (X_γ − M/D_arr)² ≤ 2MΔ` holds over all labellings of 60 tiny networks with `D_arr = r^{2a}`, largest ratio to the bound 0.49 — `misc_checks.py`.)

**3. The D.2 encoding is exact; choices made (AMBIGUITY, minor).** Claim (lines 4328–4349): clause vertex with one port per distinct variable and its satisfaction table; `(1,1)` for `d = 1`, binary equality for `d = 2`, a tree of `d − 2` trivalent equality tensors for `d ≥ 3`; subdivide every edge once; contract over `Z/2^{n+1}`; multiply by `2^u` for `u` unused variables. Computed (`d2_cnf_network.py`, exact variable elimination that assumes nothing from the paper): 1,800 random instances, `n ≤ 12`, `k ∈ {2,3,4}`, `m ≤ 3n`, with injected tautologies and repeated literals: **0 mismatches** against brute force; empty formula → `2^n`, empty clause → 0, `n = 0` → 1; the network is bipartite after subdivision. Choices the text leaves open, none affecting the contraction: the tree shape (a caterpillar), the port order `δ(v)`, and that the `d = 1` tensor is a vertex of its own.

**4. Item 4 (degree hypothesis): no gap.** For a k-CNF with one variable in every clause, the variable gadget is the equality tree, so the maximum degree before and after subdivision is `max{k, 3}` (observed 4 for `k ≤ 4`, `n ≤ 12`, `m = 3n`), the wire count is `≤ 4ks`, and `max{k,3} ≤ ⌈s^{9/10}⌉` for all `s ≥ 3` (`k = 3`), `s ≥ 12` (`k = 10`), `s ≥ 27` (`k = 20`) — in particular for all `n` from 10 to `10^6`. The splitting step is the tree "with `d − 2` internal vertices" at line 4332; it is present.

**5. The D.3 / Lemma D.2 encoding is exact at `n ≤ 6`.** Claims (lines 4377–4450): `B_i = Σ_j e_j(L̃_i) h(L̃_i)^j V^j` in `(Z/2^p)[V]/(V^ℓ)`, `p = ℓ = n+1`; its multilinear representative `B̄_i`; (D.2) `Σ_x S_ℓ(∏_i B̄_i(x, V)) ≡ #zeros (mod 2^p)`; the `V^j`-coefficient of `B̄_i` has incidence degree `≤ k(1+2j)` and every monomial of `F` has degree `≤ K = k(a + 2(ℓ−1))`; the inversion `[z_{i,S}]B̄_i = Σ_{T⊆S} (−1)^{|S|−|T|} B_i(1_T, V)`; and the network with `J = ⌈n^{1/4}⌉` groups per side, `⌈log₂ C_gh⌉` wires per pair indexing `d_gh`-subsets lexicographically, test-group entries = coefficient of the indicated monomial, variable-group entries `2^{#{v: b_v = 0}}`, unused strings → 0, summed over arrays `(d_gh)` with `Σ d_gh ≤ K`. Computed (`d3_sparse_system.py`): 22 random systems, `n ∈ {4,5,6}`, `k ∈ {2,3}`, 2–4 equations of 1–2 monomials: all five claims hold on all 22 (6–40 arrays each). Lemma 5.1's `p_ℓ(y) ≡ 1{2|y} (mod 2^ℓ)` and its division into `e_j` of degree ≤ 1 checked for `ℓ = 1..8`. Choices: round-robin group partition, lexicographic subset order, and the high-incidence branching (a substitution) was not exercised.

**6. Lemma D.5 holds as stated, with slack.** Claims (lines 4811–4951): `(D.10)` `v₂(E_t(0)) = D Σ_{j=1}^{a−i} (j/2^j)(q(i+j) − q(i)) ≥ −6Dh`; (D.9); recovery of `F(0) mod 2^p` from `F(t+αz) mod 2^{p_t}` using only the first `q_t` coefficients. Computed (`lemma_d5_hermite.py`, exact rationals, `K = Q`, `ℓ = 1`): (D.10) holds exactly for all `a ≤ 4`, `1 ≤ u ≤ a`, three `M` each (30 sets); for 10 triples `(a, u, M)` up to `a = 3, M = 4` and `p ∈ {1, 2, 5}`, 90 random `F` within the hypotheses (built from products of `W_{xy}` and `C(T)/C'(0)` multiples, degree `≤ M(2L−1)`, integrality verified): the exact identity (D.9) holds in 90/90, and after replacing the first `q_t` coefficients of each jet by random integer lifts of their residues mod `2^{p_t}` and discarding the rest, the sum is `≡ F(0) (mod 2^p)` in 90/90. The actual two-adic loss `−min_j v₂(E_t(0)(−t/α)^j)` never exceeded the budget `8hD_t + 8M(a+1)`; the smallest margin was 57 bits (loss 7, budget 64, at `a = u = M = 1`).

**7. One recursion level: Lemma D.4, (D.12), the mode divisibility and (D.16) hold on toy networks.** Claims (lines 4757–4903, 4953–5050): `W(t+αz) ∈ O[z]`, `F(t+αz) ∈ A[z]`; `v₂(t − y₀ + x) ≤ i` for crossing rows; (D.12); "the coefficient of `Z` is divisible by `2^{w_Z}`"; `(3M/L)2^{i+1}` modes per weight; `F(t+αζ) ≡ Σ_β ∏_g Z_{g,β} (mod 2^{p_t})` over tuples with `Σ w_Z β_Z < p_t`. ## What this audit does not establish

- Asymptotic claims cannot be refuted at small size. Everything in Finding 1 is a consequence of the constants the text fixes and of its own estimate (D.15); it does not touch the truth of Theorem D.1 or Theorem 1.1 as `s → ∞`. The exact tuple counts were computed at `M ≤ 16`, the large-`M` ratios are closed-form limits of the text's estimate, and the true number of nonzero children could be smaller than the number of tuples enumerated (the algorithm enumerates all tuples, so its running time is not).
- The recursion was tested one level deep, at `a = 2`, `r ∈ {2,3}`, `M ≤ 6`, `P ≤ 13`, over `K = Q` (`e = 1`, `ℓ = 1`) and with integer `ζ`; the field extension `O = Z_{(2)}[U]/(f)`, the lifting of entries across precisions, the composition children → interpolation → Lemma D.5 → `F(0)`, and the induction over `O(log λ)` levels were not run end to end (the real `p_t` makes the tuple set astronomically large even for `M = 4`). The lemmas were tested separately and compose in the obvious way, but that composition is a reading, not a computation.
- The D.3 branching on high-incidence variables, the `e = 4λ` irreducible-polynomial search, Lemma D.3's conditional-expectation derandomisation, and the space bound were not exercised.
- Findings 3–8 are finite-size (`n ≤ 12`, `n ≤ 6`, `a ≤ 4`, `M ≤ 6`); an error that only appears for `a ≥ 3`, `i ≥ 2` or `r = 64` would not have been seen, although nothing in the text's arguments depends on those sizes.
